
# LUXMY

### A little reminder. A lot of care.

LUXMY is a multilingual, voice-powered medication reminder app designed to make managing medications easier for older adults, especially those who face challenges with technology or language barriers.

The goal is to create a simple and accessible app that provides spoken medication reminders in the user's preferred language, making daily routines easier to manage.

## Why LUXMY?

LUXMY was inspired by my grandmother, Vijayaluxmy, whose name is also where the name of the app comes from.

I wanted to create something that could make technology more accessible to elderly people like her. Many older adults aren't comfortable navigating complicated apps, and language barriers can make even simple tasks frustrating.

With LUXMY, I want to explore how technology can help older adults maintain their independence while making it easier for families to support them.

## Planned Features

- **Voice Reminders:** Spoken alerts when it's time to take medication.
- **Multilingual Support:** Starting with English and Tamil, with plans to introduce more languages.
- **Medication Scheduling:** Add medications and organize reminder times.
- **Simple Interface:** Large buttons, readable text, and easy navigation.
- **Medication Tracking:** Mark reminders as taken, skipped, or postponed.
- **Family Support:** Future features allowing family members to assist with reminders and schedules.

## Development Progress

LUXMY is currently in the early stages of development.

The first version will be a browser-based prototype focusing on medication scheduling, multilingual voice reminders, and accessibility.

As the project develops, I plan to explore a mobile application with more reliable notifications, additional language support, and optional caregiver features.

## Technology

The initial prototype will use:

- HTML
- CSS
- JavaScript
- Web Speech API for voice reminders
- GitHub for version control and project management

## Disclaimer

LUXMY is currently an experimental prototype and should not be relied upon for actual medication management. The app does not provide medical advice or replace instructions from healthcare professionals.
